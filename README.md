# Retail Sales Data Analysis

## Project Overview
This project analyzes a retail sales dataset containing 1,000 transactions. The goal is to identify important sales trends, understand customer behavior, and evaluate product performance using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains information such as:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed
- Checked dataset structure, missing values, and duplicates
- Converted the Date column into datetime format
- Analyzed total sales by product category
- Compared transaction counts across product categories
- Calculated average transaction value
- Analyzed monthly sales trends
- Compared sales by customer gender
- Created customer age groups and analyzed sales by age group
- Calculated key business metrics

## Key Findings
- Electronics generated the highest total revenue.
- Clothing had the highest number of transactions.
- Beauty had the highest average transaction value.
- May was the strongest sales month in 2023.
- September was the weakest sales month in 2023.
- Female customers generated slightly more revenue than male customers.
- Customers aged 46–55 generated the highest sales among the age groups.

## Key Metrics
- Total Revenue: $456,000
- Total Items Sold: 2,514
- Average Transaction Value: $456
- Total Transactions: 1,000

## Visualizations
The project includes visualizations for:
- Total Sales by Product Category
- Monthly Sales Trend
- Total Sales by Gender
- Total Sales by Age Group

## Conclusion
This analysis shows how Python and Pandas can be used to transform raw retail transaction data into useful business insights. The project demonstrates data cleaning, exploratory data analysis, grouping, aggregation, datetime analysis, customer segmentation, and data visualization.
